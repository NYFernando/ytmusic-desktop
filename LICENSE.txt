ABOUT THIS APPLICATION
--------------------------------------------------------------------------------
YouTube Music Desktop is a next-generation desktop music player designed for
audiophiles, gamers, and music lovers.

KEY FEATURES INCLUDED:
• 🎛️ 10-Band Graphic Equalizer & Acoustic Studio with 8 Presets & Bass Boost
• 🪟 Picture-in-Picture (PiP) Frameless Floating Mini Player Widget
• 📥 High-Speed Resumable Song & Playlist Offline Download Manager
• 🎨 Theme Studio (Cyberpunk Crimson, Tokyo Cyan, Matrix Emerald, Synthwave, OLED)
• ⏳ Smart Sleep Timer with smooth volume fade-out
• ⌨️ Global System-Wide Keyboard Media Hotkeys
• 💬 Discord Rich Presence Integration with live track artwork
• 🔒 1-Click Cookie Account Sync (Zero setup / Zero Python required)
